# 서울 아파트 시장 분류

`seoul_market_monthly.json`은 한국은행 ECOS가 제공하는 KB국민은행 **서울 아파트 매매가격지수** 월별 자료의 고정 스냅샷입니다.

- 통계표: `901Y062`, 항목: `P63ACA`, 주기: `M`
- 기간: 2005년 12월~2025년 12월 (241개월)
- 기준: 2026년 1월=100, 확인일: 2026-09-11
- 공식 조회 예: https://ecos.bok.or.kr/api/StatisticSearch/sample/json/kr/1/10/901Y062/M/202506/202512/P63ACA/
- 재수집: 저장소 루트에서 `python scripts/fetch_market_index.py`

상반기는 6월/전년 12월, 하반기는 12월/같은 해 6월 지수를 비교합니다. 지수가 낮아진 반기는 하락기, 높아진 반기는 상승기, 같으면 보합입니다. 회색 음영과 국면별 거래 건수 비교는 이 반기 분류를 따릅니다. 연간 배지는 12월/전년 12월로 별도 계산합니다. **반기 내 모든 달의 가격이 하락했다는 뜻은 아닙니다.** 2026년 이후는 미분류입니다.

기존 한국부동산원 연간 분류를 KB의 일관된 월별 계열로 교체했습니다. 기관별 지수의 차이로 이전 표시와 달라질 수 있습니다. 앱 실행 시 외부 지수를 재조회하지 않으므로 추가 API 키나 네트워크 호출은 필요하지 않습니다.
